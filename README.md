# WeRide — University Student Carpooling App

WeRide is a Flutter-based mobile application prototype designed to help university students find and share rides.

## Project Overview

This project is being developed for the Mobile App Development semester course. It focuses on essential carpooling features using Flutter and Firebase.

## Core Features

- Student registration, login, and profile management
- Ride posting and searching
- Basic ride matching
- Ride booking and seat availability updates
- Shared-fare calculation
- Simulated SOS alert

## Technology Stack

- Flutter and Dart
- Visual Studio Code
- Firebase Authentication
- Cloud Firestore
- Git and GitHub
- Figma for UI/UX design (planned)

## Project Components

1. UI/UX Design
2. UI Navigation and Integration
3. Application Functionalities
4. Database and Firebase Integration

## Scope

Advanced AI matching, live GPS tracking, in-app chat, professional drivers, smart scheduling, and real payment processing are excluded from this prototype.

## Development Timeline

- Month 1: Planning, UI design, and setup
- Month 2: Core features and database integration
- Month 3: Testing, documentation, and demonstration
